# 游戏内存档迁移与版本升级系统

## 项目描述

游戏内存档迁移与版本升级系统的bug修复项目。核心模块 `db/migration.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 版本检测完全没做不知道存档是哪个版本
- schema迁移完全没做老版本字段读不出来
- 数据迁移完全没做老格式数据在新版本全错
- 回滚完全没做迁移失败后存档就没了
- 兼容性处理完全没做新版本能读老存档但数据全错

## 运行测试

```bash
python -m pytest tests/test_migration.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
